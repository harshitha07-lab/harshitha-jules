# Hello World Project

This repository contains a simple, clean, and idiomatic Python "Hello, World!" application.

## Requirements

- Python 3.8 or higher
- `pytest` (for running unit tests)

## Usage

To run the main application:

```bash
python3 main.py
```

Expected output:
```
Hello, World!
```

## Running Tests

To run the unit tests using `pytest`:

```bash
pytest
```
